# RO3 on LITNODE: player launcher

Downloads for the RO3 on LITNODE player launcher, the one-file Windows app that downloads Ragnarok Online 3 from the
publisher's official servers, patches it for community servers such as New Prontera, finds them through the LITNODE
mesh and plays.

**[Download the latest Ro3EmuLauncher.exe](https://github.com/strodanodev/ro3-launcher/releases/latest/download/Ro3EmuLauncher.exe)**

- Windows 10/11. A single file: nothing to install, no .NET, no port forwarding.
- The ~24 GB game client comes from the publisher's official update servers, never from here.
- The launcher is unsigned. If Windows says "protected your PC", choose More info, then Run anyway.

How to install and play: https://new-prontera.vercel.app

This repository only hosts release files. The launcher is free software under the GNU GPL v3.
